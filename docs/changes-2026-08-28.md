# 8月28日客户反馈修改说明

## 本次功能

1. 订单管理增加搜索框，支持图号、物料编码、订单号和名称的部分匹配；可清除搜索并查看匹配数量。图号优先使用订单图号，没有时使用工件图号。
2. 订单管理增加“指定加工人员”：选择本工厂在岗人员、填写原因后保存。只约束所选订单，不改变同类工件或其他订单。重新排产优先使用人工指定人员；重新导入匹配到同一订单时保留该设置。选择“自动匹配”可取消指定。
3. 可勾选“同时转派此订单的已有派工”，保留原日期和工作量；目标员工当天累计工作量超过含加班上限时阻止转派，提示先取消勾选并重新排产。历史快照不改写。
4. 排产结果的“人工调整”使用人员下拉选择。修正显示行副本与原始行对象不一致导致调整未保存的问题。该入口只调整当前一条派工；若整单以后都要固定员工，请使用订单管理的人员指定。

## 建议客户验证

- 导入表格后按一个实际图号搜索，核对订单、数量、工厂是否正确。
- 找到需要人工决定加工人员的订单，指定员工并保存，再次打开核对。
- 重新生成排产，确认该订单分给指定员工，其他同类订单不被一起指定。
- 勾选同步转派，确认只改变当前订单；超出目标人员上限时应出现提示。
- 单条派工点击“人工调整”，选择另一位员工保存，刷新后核对实际员工和数量。
- 再次导入同一订单，确认人工指定保留；取消指定后重新排产恢复自动匹配。

请使用测试订单或先留存当前计划，不要用正式已发布计划做破坏性测试。
